## 1. 작업 목적

2026학년도 교양 이수요건과 교양 교과목, 컴퓨터공학과 교육과정이 담긴 19쪽 PDF 전체를 에이전트가 직접 시각 판독하고, `ontology/ontology_spec.json`에 맞는 Neo4j 적재 전 기준 데이터 JSON으로 큐레이션하는 것이 목적이었다.

## 2. 요청 내용 요약

- 원본 19쪽 PDF를 전처리·OCR·변환 없이 직접 읽는다.
- 발췌 1~13쪽의 교양 규칙과 모든 교양 교과목을 구조화한다.
- 발췌 14~19쪽의 컴퓨터공학과 학점구조, 모든 전공 교과목과 경과조치를 구조화한다.
- 모든 확정 Rule과 CourseOffering에 짧은 원문 및 3종 페이지 번호를 가진 Evidence를 연결한다.
- 애매하거나 현재 명세로 표현할 수 없는 사실은 별도 미결정 목록에 남긴다.
- 전체 직접 대조가 끝난 경우에만 커밋·push·Draft PR을 수행한다.

## 4. 수행한 작업

### 첫 번째 시도: 로컬 PDF

- 로컬 PDF 파일의 존재, 페이지 수, 크기와 SHA-256을 확인했다.
- 기존 환경에서 사용할 수 있는 PDF 화면 렌더러와 Python PDF 라이브러리 존재 여부를 확인했다.
- 새 의존성을 설치하지 않고 내장 이미지 열람기로 PDF를 직접 열 수 있는지 시험했다.
- 내장 열람기가 PDF를 처리하지 못했고, 사용 가능한 직접 시각 판독 수단이 없어 작업을 중단했다.
- 페이지 내용을 보지 못한 상태에서 숫자·과목·학사규칙을 추정해 만들지 않았다.

### 두 번째 시도: 대화 첨부 PDF

- 사용자가 같은 PDF를 대화 첨부파일로 제공했다고 알려 재개를 요청했다.
- 현재 세션에서 대화 첨부 PDF의 페이지를 열거나 화면으로 요청할 수 있는 첨부파일 열람 인터페이스가 노출됐는지 확인했다.
- 일반 첨부파일 마운트 위치에서도 별도 PDF 첨부본을 확인하지 못했다.
- 로컬 PDF로 우회하거나 추출·렌더링·OCR 도구를 사용하지 않았으며, 직접 판독 조건이 다시 충족되지 않아 재중단했다.

## 6. 주요 결정과 이유

- PDF 페이지와 표의 행·열을 직접 보지 못했으므로 어떤 사실도 `VERIFIED`로 만들지 않았다.
- 온톨로지 명세의 예시 ID나 이전 문서의 대표 질의 값을 실제 PDF 데이터처럼 재사용하지 않았다.
- 빈 데이터 파일은 진행 결과로 오해될 수 있으므로 만들지 않았다.
- 첫 실패와 첨부 PDF 재시도는 같은 데이터 큐레이션 목표이므로 별도 로그 번호를 만들지 않고 `0004`에 함께 기록했다.

## 8. 발견된 문제와 위험

- 현재 세션에서는 대화 첨부 PDF를 페이지 단위로 직접 볼 수 있는 인터페이스가 노출되지 않았다.

- 19쪽 전체의 교양 과목, 전공 과목, 각주와 경과조치는 모두 아직 미확인이다.

## 9. 남은 작업

- 발췌 1~19쪽을 모두 직접 판독한다.
- 기준 데이터 JSON, 필요한 미결정 항목 JSON과 데이터 설명 문서를 작성한다.

## 11. 후속 경과: Raw 데이터 기준선 반입

VS Code Codex 환경에서 두 차례 PDF 직접 판독이 불가능해 데이터 생성을 중단한 뒤, 별도의 웹 생성형 AI 세션에서 19쪽 PDF와 `ontology/ontology_spec.json`을 직접 판독하여 다음 JSON 두 개를 생성했다.

- `data/raw/2026_curriculum_kg_data.json`
- `data/raw/2026_curriculum_unresolved.json`

사용자가 생성된 두 JSON을 현재 저장소의 `data/raw/`에 직접 배치했다. 이번 로컬 작업에서는 JSON 내용의 정정, 스키마 확장, `data/verified/2026/` 정제본 생성과 Neo4j 적재를 수행하지 않았다. 두 파일은 웹 세션의 최초 원문 판독 결과와 이후 정제 결과를 비교하기 위한 수정 전 Raw 기준선이며, 이후 작업에서도 직접 수정하지 않는다.

다음 정정사항은 확인됐지만 이번 Raw 기준선에는 반영하지 않고, 후속 작업에서 `data/verified/2026/` 정제본을 만들 때 원문값과 정정값을 분리하여 반영할 예정이다.

- `GEA8617`: 수식없는물리로보는세상
- `GEA8817`: 융합프로젝트Ⅰ
- 컴퓨터공학과 전공 교과목 편성표 실기 시수 합계: 원문 12, 정정값 14

이번 기준선 검사에서 두 JSON 모두 JSON 구문이 유효함을 확인했다. KG 파일은 노드 1,115개와 관계 1,946개를 포함하며 metadata 개수와 실제 배열 개수가 일치했다. 중복 노드 ID와 존재하지 않는 관계 endpoint는 발견되지 않았다. 정정 대상 값은 확정 KG 노드에 임의 적용되지 않았고 unresolved 파일에 원문 충돌 또는 합계 불일치로 보존돼 있었다.
